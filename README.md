# QyLock Oma — theme catalog

Lightweight catalog for the [qylock-oma](https://github.com/mjtiempo/qylock-oma)
Omarchy plugin: the theme **list** (`index.json`) + small **preview images**
used to populate the theme grid.

The heavy theme assets (videos, images, QML) are **not** here — the plugin
fetches them on demand (Apply / Preview) from the upstream source:

- **Source of the themes:** [Darkkal44/qylock](https://github.com/Darkkal44/qylock)
- Previews were derived from qylock's `Assets/` gallery (first frame, resized)
  or each theme's background art.
